## 🔧 문제 해결 가이드

### 해결된 주요 문제들

#### 관리자 접근 문제 (v1.4에서 해결됨)
```
증상: 로그인 후 wp-admin 접근 시 500 에러
해결: v1.4에서 완전 해결됨 (URL 설정 통일, 권한 복구)
예방: Local WP 재시작 후에도 정상 작동 확인됨
```

#### 팝업스토어 날짜 표시 문제 (v1.6에서 해결됨)
```
증상: 모든 팝업스토어가 "1.1 - 1.1"로 동일 표시
해결: v1.6에서 메타필드키 수정으로 해결
확인: 현재 모든 팝업스토어 실제 운영 기간 정확 표시
```

#### 장소 관리 컬럼 중복 표시 (v1.9에서 해결됨)
```
증상: "🍽️ 맛집맛집", "🟢 운영중미설정" 등 중복 텍스트 표시
해결: v1.9에서 중복 컬럼 시스템 비활성화로 해결
확인: 현재 모든 장소 정확한 단일 정보 표시
```

#### 새로 발견된 성능 문제 (v2.0에서 발견)
```
증상: functions.php 40.83KB로 페이지 로딩 지연, 메모리 사용량 증가
분석: WordPress 권장 기준 279% 초과, 모놀리식 구조 문제
계획: 4단계 리팩토링으로 66% 크기 감소 및 20-30% 성능 향상
```

#### 일반적인 해결 방법
```bash
1. 사이트 로딩 안됨 → Local WP 재시작
2. 스타일 적용 안됨 → 브라우저 캐시 삭제  
3. DB 연결 오류 → wp-config.php 설정 확인
4. 권한 오류 → 관리자 대시보드에서 사용자 관리 확인
5. functions.php 오류 → 백업 파일로 즉시 복원 (v2.0 추가)
```
