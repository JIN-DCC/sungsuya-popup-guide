🔧 네이버 지도 API 문제 해결 가이드

도메인 인증 실패 문제를 완전히 해결하는 방법

❌ 확인된 문제

문제: 지도 타일 로드 완료 후 naver.maps 객체가 null이 되며 지도가 사라짐

원인: 네이버 클라우드 플랫폼에서 sungsuya-v2.local 도메인이 등록되지 않아 인증 실패

증상: API 로드는 성공하지만 렌더링 과정에서 DOM 노드가 제거됨

✅ 해결 방법

네이버 클라우드 플랫폼에서 Web 서비스 URL에 로컬 개발 도메인을 추가해야 합니다.

🔑 1단계: NCP 콘솔 접속

네이버 클라우드 플랫폼 콘솔에 로그인하세요.

NCP 콘솔 열기

🗺️ 2단계: Maps 서비스 설정

경로: AI·Application Service → Maps → Application 관리

현재 등록된 Application: sungsuya-v2

💡 팁: Application 목록에서 "sungsuya-v2"를 찾아 클릭하세요.

🌐 3단계: Web 서비스 URL 수정

현재 등록된 URL 목록에 로컬 개발 도메인을 추가해야 합니다.

📋 추가해야 할 도메인들

http://sungsuya-v2.local http://sungsuya-v2.local/ https://sungsuya-v2.local https://sungsuya-v2.local/ http://localhost http://localhost/ http://127.0.0.1 http://127.0.0.1/

⚠️ 중요: 기존 URL들은 삭제하지 말고, 위의 도메인들을 추가하세요!

💾 4단계: 설정 저장 및 대기

변경사항을 저장한 후 5-10분 정도 기다리세요.

참고: NCP Maps API는 도메인 설정 변경 후 즉시 적용되지 않습니다.

🧪 5단계: 테스트

설정 변경 후 아래 링크들로 테스트하세요:

진단 페이지 재테스트 순수 테스트 페이지

🔄 대안 1: hosts 파일 수정 (즉시 해결)

도메인 설정 대기 시간 없이 즉시 해결하려면:

# Windows: C:\Windows\System32\drivers\etc\hosts 파일에 추가 127.0.0.1 production-domain.com # 그리고 NCP에서 production-domain.com 등록

주의: 이 방법은 개발용으로만 사용하세요.

🌍 대안 2: 실제 도메인 사용

실제 도메인을 사용하여 테스트:

  • Ngrok 또는 Cloudflare Tunnel 사용
  • 실제 웹 서버에 업로드
  • GitHub Pages 등 무료 호스팅 활용

✅ 성공 확인 방법

  • 지도가 사라지지 않음 - 가장 중요한 지표
  • 콘솔 오류 없음 - naver.maps null 오류 해결
  • NCP 사용량 집계 - 클라우드 플랫폼에서 API 호출 횟수 확인됨
  • 마커 클릭 가능 - 모든 지도 기능 정상 작동

💡 개발 팁

  • 개발 환경: localhost, 127.0.0.1, *.local 도메인 모두 등록
  • 프로덕션: 실제 도메인 등록 (www 포함/미포함 모두)
  • HTTPS: HTTP, HTTPS 모두 등록 권장
  • 경로: 루트(/) 경로와 서브경로 모두 고려

📞 문제 지속 시

위 단계를 모두 따라했는데도 문제가 지속된다면:

  • NCP 고객센터 문의 (기술지원)
  • 새로운 Application 생성 시도
  • 다른 브라우저에서 테스트
  • 캐시 완전 삭제 후 재시도
